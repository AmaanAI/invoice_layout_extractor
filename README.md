# Multilanguage Invoice Extractor

A Streamlit application that uses advanced generative AI technology to extract and replicate the entire content of invoice documents in markdown format. This app is designed to process multilingual invoices and retain the structure, format, and content of the original document.

## Features

- **Sequential Parsing:** Replicates the entire document content from top to bottom, maintaining the original order.
- **Markdown Format Output:** Extracts text, tables, and other structured data from invoices and converts them into markdown format.
- **Preserves Layout:** Ensures the output accurately reflects the original document, including tables, headings, and paragraphs.
- **Multilingual Support:** Handles invoices in multiple languages.
